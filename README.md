# Amazon Clone 🛒

A full-featured responsive replication of the Amazon e-commerce platform. This project focuses on complex UI layouts, multi-product display grids, state management for a shopping cart, and realistic interactive checkout simulations.

## 🚀 Features

* **Interactive Shopping Cart:** Real-time adding, removing, and updating of item quantities with dynamic subtotal calculations.
* **Product Catalog Grid:** A clean multi-row layout showcasing product images, pricing, ratings (star icons), and "Add to Cart" actions.
* **Amazon Header Navigation:** Fully replicated navigation bar containing the delivery location selector, categorized search bar, account dropdown menus, and the real-time cart counter.
* **Interactive Image Carousel:** A functional homepage hero banner that cycles through promotional images just like the real Amazon homepage.
* **Simulated Checkout:** A stylized checkout view calculating shipping fees, simulated taxes, and order totals.
* **Responsive Architecture:** Built with a mobile-first approach, hiding or collapsing complex desktop navigation elements gracefully on smaller touch screens.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic architecture to structure complex product lists and checkout modules.
* **CSS3:** Heavy use of CSS Grid for the product showcase layout, custom animations for the carousel, and media queries for responsive adjustments.
* **JavaScript (ES6+):** Manages application state (tracking items in the cart, recalculating totals) and dynamic DOM updates when users interact with products.
